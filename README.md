# Sachin Kumar Angular Portfolio

## Run
1. Install Node.js 20+
2. `npm install`
3. `npm start`
4. Open http://localhost:4200

## Customize
Edit:
- `src/app/app.component.ts` for projects/experience/skills
- `src/app/app.component.html` for sections/content
- `src/styles.css` for the visual design

The design is original and inspired by modern developer portfolio patterns.
